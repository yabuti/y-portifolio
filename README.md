# Portfolio 2018 Website

This folder contains a simple website wrapper for `portfolio 2018.pdf`.

## How to use

1. Open `index.html` in your browser.
2. The PDF will be displayed inside the page.
3. If the PDF does not render, click the link to open it directly.

## Files

- `index.html` — website page that embeds the PDF.
- `styles.css` — styling for the page.
- `portfolio 2018.pdf` — original PDF file.
